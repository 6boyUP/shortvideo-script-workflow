# shortvideo-script-workflow · 短视频选题脚本工作流

输入一个行业名，产出 5 条能直接开拍的短视频方案。每条自带**时效证据、可被反驳的核心判断、3 版不同机制的开头钩子、带时长配比的脚本结构、分层话题标签、有推导依据的发布时间**。

适用于抖音 / 小红书 / 视频号 / B站，不限行业，B 端 C 端通用。

## 它解决什么问题

打开 AI 输入「帮我写个短视频脚本」，得到的是一段读起来正确、但换任何人都能写的废话。问题不在模型，在输入——你只给了一个词，它只能还你一个平均值。

这套流程把选题拆成流水线：情报检索 → 行业解构 → 15 个候选 → 打分淘汰到 5 个 → 配齐执行参数。每一步都有可检查的产物，跳步就会退化成行业科普。

## 为什么能跨行业

它不靠行业模板库（行业上千个，覆盖不过来），靠的是「内容机会所在的位置」。任何行业值得讲的东西只从四个地方长出来：

| 位置 | 内容来源 | 产出类型 |
|---|---|---|
| 外部变化 | 政策、涨价、技术、事件 | 时效型 |
| 内部矛盾 | 便宜与耐用、快与好 | 决策型 |
| 认知错位 | 用户以为 A，实际是 B | 反常识型 |
| 从业者视角 | 行业内人人皆知、外行一无所知 | 内幕型 |

位置不变，行业换了，内容换一遍。

再叠加**五原型配额制**：5 条必须分属 5 个不同原型，不允许重复。不设配额，模型一定给你 5 条「避坑指南」——那是它最省力的路径。

## 安装

### 方式一：直接放进 skills 目录

```bash
git clone https://github.com/<your-name>/shortvideo-script-workflow.git \
  ~/.workbuddy/skills/shortvideo-script-workflow
```

重开一个会话即生效。

### 方式二：用打包好的 zip

下载 `shortvideo-script-workflow.zip`，解压到 `~/.workbuddy/skills/`，确认目录结构为 `~/.workbuddy/skills/shortvideo-script-workflow/SKILL.md`。

## 用法

在 WorkBuddy（或任何支持 Skill 的 Agent 环境）里直接说：

```
帮我看下「本地口腔诊所」这个行业最近有什么值得讲的选题
```

```
我是做工业除尘设备的，想在视频号起号，给我 5 个选题
```

```
这条选题的钩子不行，帮我重写三版：#孩子换牙不齐要不要矫正
```

也支持只调用某一环：单独要钩子、单独要话题标签、单独要发布时段。

## 目录结构

```
shortvideo-script-workflow/
├── SKILL.md                      # 主流程与硬约束（触发时加载）
└── references/
    ├── prompts.md                # 主控提示词 + 单步提示词 ×7，可直接复制
    ├── cheatsheet.md             # 钩子六机制 / 四种骨架 / 时长配比 / 受众时段 / 参数默认
    └── quality-gate.md           # 12 项自检 + 八种失败模式与修法
```

SKILL.md 只放流程和约束，细节拆进 references 按需加载，避免占用上下文。

## 输出长什么样

一条选题的完整形态：

```
【选题 1】同一颗牙，两家报价差 6800
原型：决策型
时效证据：【2026-08】【政策】耗材集采范围扩大，多地种植牙耗材价格体系调整
核心判断：报价差异的大头不在医生技术，在材料等级和打包项目——拿总价比价，本身就是错的比法
钩子 A｜损失厌恶：同一颗牙，两家报价差 6800，差价不在技术上
钩子 B｜冲突对峙：医生说必须拔，诊所报 8000，我劝你先做这一件事
钩子 C｜结果前置：我帮 40 个客人平均省下 5000 块，方法只有一句话
脚本结构：决策清单式，3 分钟版（0-35 秒摆报价单 / 35-120 秒三个判断维度 / 120-180 秒给唯一结论）
话题标签：口腔健康｜种植牙、牙齿修复、看牙贵｜种植牙多少钱一颗、报价包含什么、看牙怎么不被坑、集采后价格
发布时间：12:00-13:00 / 20:30-22:00 / 7:00-8:00（受众为 30-50 岁上班族与家庭决策者）
变现钩子：把你的报价单发我，我帮你拆三项
```

## 六条硬约束

违反任一条即判本次输出失败：

1. 不许出现「要重视」「很关键」「因人而异」这类不可证伪的表述
2. 不许 5 条同属一个原型
3. 不许把行业通识包装成选题
4. 时效证据必须可追溯，编不出就写「未检索到」
5. 钩子必须有具体名词或数字，不许「你知道吗」开头
6. 发布时段必须从受众作息推导，不许「晚上 8 点最好」

## 它做不到什么

能替你完成 80% 的结构性劳动，但决定不了立场，也给不了经历。五条里最终能爆的那条，往往是因为你在这件事上真吃过亏。
