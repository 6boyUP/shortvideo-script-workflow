# 速查表

## 表 1 · 钩子六机制

| 机制 | 公式 | 示例（口腔诊所） | 最适合 | 别用的情况 |
|---|---|---|---|---|
| 损失厌恶 | 你正在为【X】多付【Y】，而【Z】 | 同一颗牙，两家诊所报价差 6800，差价不在技术上 | 决策型 | 没有真实金额时 |
| 反常识 | 做了【N】年【行业】，我最不建议的是【X】 | 做了 12 年牙医，我最不建议买的是全家套餐 | 反常识型 | 身份不真实时 |
| 身份点名 | 如果你是【具体人群】，这条看完 | 如果你正在给孩子做矫正，这条一定看完 | 情绪型 | 人群说不具体时 |
| 结果前置 | 我用【时间】把【X】做到【Y】，只有 3 步 | 我帮 40 个客人平均省下 5000 块，方法只有一句话 | 全类型 | 没有真实结果时 |
| 冲突对峙 | 【A】说……【B】说……我站【C】 | 医生说必须拔，诊所报 8000，我劝你先做这一件事 | 决策型 | 冲突是编的时候 |
| 悬念缺口 | 【行业】有个规矩，没人主动告诉你 | 报价单上有一项，我从来不主动解释 | 内幕型 | 一条视频只能用一次 |

## 表 2 · 脚本骨架

| 骨架 | 适用原型 | 分段逻辑 | 核心要求 |
|---|---|---|---|
| 反常识三段式 | 反常识型 | 推翻常识 → 解释原因 → 给出正确做法 | 第一段直接给结论，不许铺垫 |
| 诊断式 | 情绪型、决策型 | 说出现象 → 主流解释（错的） → 真正原因 → 可执行方案 | 「主流解释是错的」要具体到某个流行说法 |
| 决策清单式 | 决策型 | 摆出选项 → 三个判断维度 → 明确结论 | 结论唯一，不许「看情况」 |
| 故事弧 | 情绪型、内幕型 | 一个人物 → 他的困境 → 一个转折 → 结论 | 人物要有具体身份处境，不能是「我有个朋友」 |

## 表 3 · 时长配比（单位：秒）

| 骨架 | 60 秒 | 3 分钟 | 5 分钟 |
|---|---|---|---|
| 反常识三段式 | 10 / 25 / 25 | 30 / 70 / 80 | 45 / 110 / 145 |
| 诊断式 | 12 / 15 / 18 / 15 | 35 / 40 / 55 / 50 | 50 / 60 / 90 / 100 |
| 决策清单式 | 15 / 30 / 15 | 35 / 85 / 60 | 50 / 130 / 120 |
| 故事弧 | 20 / 20 / 20 | 50 / 60 / 70 | 70 / 90 / 140 |

语速按每分钟 260 字估算。3 分钟约 780 字，超过 20% 就砍内容，不要靠念快。

## 平台差异（话题标签）

| 平台 | 话题的角色 | 优先级 |
|---|---|---|
| 抖音 | 分发标签 | 大词负责进池，中词负责精准度，长尾词作用有限。堆无关大词会被判蹭流量，反而压推荐 |
| 小红书 | 搜索入口 | 长尾词优先于中词，中词优先于大词。写「用户会怎么搜」，不写「平台怎么分类」 |

## 参数默认值

| 参数 | 可选值 | 默认 |
|---|---|---|
| 行业 | 任意，越具体越好 | 必填 |
| 平台 | 抖音 / 小红书 / 视频号 / B站 | 抖音 |
| 账号阶段 | 0-1 起号 / 有基础粉丝 / 已有产品在卖 | 0-1 起号 |
| 变现方式 | 卖课 / 卖货 / 到店 / 咨询 / 无 | 无 |
| 目标受众 | 身份 + 年龄段 + 城市层级 | 由行业推断 |
| 选题数量 | 5（推荐）/ 10（做选题库） | 5 |
| 目标时长 | 60 秒 / 3 分钟 / 5 分钟 | 按平台 |
| 钩子数量 | 3 版（推荐）/ 5 版 | 3 版 |

三组固定配比：

- 选题原型：时效、反常识、决策、内幕、情绪，各 1 条。
- 话题标签：大词 1、中词 3、长尾词 4。
- 语速：每分钟 260 字，3 分钟约 780 字。
