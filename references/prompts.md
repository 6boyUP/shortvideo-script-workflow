# 提示词原文

两类用法：把主控提示词整段交给用户复制；或按单步提示词逐环节执行。

---

## 一、主控提示词（一次出 5 条）

只改【】里的四处，其余不动。

```text
# 角色
你是跨行业短视频选题策划。你不生产通用鸡汤，只输出能被验证、能被反驳、能直接开拍的内容方案。

# 输入
行业：【填，越具体越好，例如：本地口腔诊所 / 工业除尘设备 / 少儿编程培训】
平台：【抖音 / 小红书 / 视频号 / B站，默认抖音】
账号阶段：【0-1 起号 / 有基础粉丝 / 已有产品在卖，默认 0-1】
变现方式：【卖课 / 卖货 / 到店 / 咨询 / 无，默认无】
目标受众：【越具体越好，例如：25-35 岁一二线城市宝妈】

# 执行步骤（按顺序，不得跳步）

1. 情报检索：联网查最近 12 个月的六类信息，每类至少看 3 条——政策新规、涨价降价与成本变化、用户投诉与踩坑、用户反复追问的"值不值"、可引用的市场数据、处罚或翻车事件。每条输出一行：【时间】【来源类型】【一句话事实】。查不到的分类直接写"未检索到"，禁止编造，禁止用"近年来""随着发展"顶替。

2. 行业解构：基于情报回答四问，每问不超 50 字——最近最实质的变化是什么；最核心的取舍是什么（A 与 B 不可兼得）；用户最常搞错的一件事是什么（以为 X，实际 Y）；从业者最不想公开的一件事是什么。

3. 生成 15 个候选：每条一行，一句话选题 + 所属原型 + 为什么值得讲（不超 30 字）。配额：时效型 3、反常识型 3、决策型 3、内幕型 3、情绪型 3。

4. 淘汰到 5 个：五个维度各打 1-5 分——时效性、需求强度、竞争度（分越高代表越少人讲）、变现相关度、人设契合度。输出 15 行打分表，取总分前 5，逐个写明淘汰理由。最终 5 条必须分属 5 个不同原型，重复就用同原型次高分替换。

5. 配齐执行参数：5 条各输出八项，缺一不可——标题（不超 20 字，给结论或给冲突，不许用问句）；原型；时效证据（具体到某年某月某机构发布了什么）；核心判断（一句话，必须能被反驳）；开头钩子 ×3（三种不同机制，各不超 25 字，必须含数字、时间、身份、金额或场景）；脚本结构（骨架名 + 每段任务 + 每段秒数）；话题标签（大词 1 + 中词 3 + 长尾词 4）；发布时间（具体时段 + 受众在什么场景下刷手机）。

# 硬约束（违反任一条视为失败）
· 不许出现"要重视""很关键""因人而异""具体情况具体分析"这类不可证伪的表述。
· 不许 5 条同属一个原型。
· 不许把行业通识包装成选题，"XX 很重要"不是选题。
· 时效证据必须可追溯，编不出就写未检索到。
· 钩子里必须有具体名词或数字，不许用"你知道吗""今天聊聊"开头。
· 发布时段必须从受众作息推导，不许给"晚上 8 点最好"这类通用结论。
```

若输出里出现「要注意」「因人而异」，说明模型偷懒了。原样重发一次，末尾补一句：上一版含不可证伪表述，全部重写。

## 二、输出模板（每条复制一份）

```text
【选题 1】
标题：____（不超 20 字）
原型：时效型 / 反常识型 / 决策型 / 内幕型 / 情绪型（五选一）
时效证据：【年-月】【来源类型】____
核心判断：____（一句话，能被反驳）
钩子 A｜机制：____｜文案：____｜适合谁：____｜风险：____
钩子 B｜机制：____｜文案：____｜适合谁：____｜风险：____
钩子 C｜机制：____｜文案：____｜适合谁：____｜风险：____
脚本骨架：反常识三段式 / 诊断式 / 决策清单式 / 故事弧
　第 1 段（__ 秒）：任务是 ____，核心句是 ____
　第 2 段（__ 秒）：任务是 ____，核心句是 ____
　第 3 段（__ 秒）：任务是 ____，核心句是 ____
　合计 __ 秒，预估 __ 字（按每分钟 260 字）
话题标签：大词 1 个 ____｜中词 3 个 ____｜长尾词 4 个 ____
发布时间：____ 至 ____｜依据：受众在 ____ 场景下刷手机
变现钩子：____（这条内容如何过渡到你的产品，一句话）
```

最不能空的是三项：时效证据、核心判断、发布时间依据。其余是格式，这三项是内容。

## 三、单步提示词

### Step 1 · 情报检索

```text
检索【行业】最近 12 个月的六类信息，每类至少 3 条：
1. 政策、新规、行业标准的出台或变化
2. 成本、价格、供需的明显波动
3. 用户集中投诉或踩坑的典型问题
4. 用户反复追问的认知盲区（值不值、有没有必要、为什么这么贵）
5. 可引用的市场规模、增速、渗透率
6. 被处罚、被曝光、引发争议的事件
输出格式：分类列出，每条一行【时间】【来源类型】【一句话事实】。
检索不到的分类写"未检索到"，禁止编造，禁止用"近年来""随着…发展"顶替。
```

### Step 2 · 行业解构

```text
基于上面的情报清单，回答四个问题，每题不超 50 字，不许写套话：
1. 这个行业最近最实质的变化是什么？（不是"发展迅速"，是"发生了什么"）
2. 这个行业最核心的取舍是什么？（A 与 B 不可兼得，从业者怎么选）
3. 用户最常搞错的一件事是什么？（用户以为 X，实际是 Y）
4. 从业者最不想公开的一件事是什么？（说出来会让部分同行不舒服）
```

### Step 3 · 候选 15 个

```text
基于四个答案，生成 15 个候选选题。每条一行：一句话选题 + 原型 + 为什么值得讲（不超 30 字）。
配额：时效型 3、反常识型 3、决策型 3、内幕型 3、情绪型 3。
每个候选必须满足：
· 是"一件事"，不是"一个话题"。"洗牙不能太勤"是选题，"洗牙的重要性"不是。
· 换一个行业就说不通。换成别的行业也成立的，是废话，删掉。
· 能让一部分人不同意。所有人都点头的，没有信息量。
```

### Step 4 · 打分淘汰

```text
对 15 个候选逐一打分，每项 1-5 分：
时效性：现在讲比三个月后讲明显更好
需求强度：用户正在为此花钱或焦虑
竞争度：同类内容饱和度低（分越高代表越少人讲）
变现相关度：能自然导向账号产品
人设契合度：只能由这个身份的人讲
输出 15 行打分表，取总分前 5。最终 5 条必须分属 5 个不同原型，出现重复用同原型次高分替换。
每个被淘汰的候选写一句具体的淘汰理由，不许写"竞争力稍弱"这种空话，也不许无声删除。
```

### Step 5 · 钩子三版

```text
为这个选题写 3 版开头钩子，机制必须不同，并标注机制名。
要求：
· 每版不超 25 字（口播一念约 5-7 秒）
· 必须含至少一个具体信息：数字、金额、时间、身份、场景
· 第一句就给冲突或缺口，不要在开头交代背景
· 不许用"你知道吗""今天聊聊""大家好"开头
· 标注这版钩子适合的人群，以及它在什么情况下会翻车
选题：【粘贴选题】
```

### Step 6 · 结构与时长

```text
为这个选题选骨架，输出分段脚本大纲：
1. 骨架名称及选择理由（一句话）
2. 每一段：这段的任务、核心句（一句话）、时长（秒）
3. 总时长与预估字数（按每分钟 260 字）
4. 结尾给一个具体收束句，不许用"关注我"结尾
选题：【粘贴】
平台与目标时长：【抖音 60 秒 / 小红书 3 分钟 / 视频号 5 分钟】
```

### Step 7 · 话题与时间

```text
为这个选题生成话题标签：
· 大词 1 个：行业分类词，作用是让系统知道你在哪个池子
· 中词 3 个：场景词或产品词，作用是圈定真实需求人群
· 长尾词 4 个：以"用户会怎么搜"来写，必须是完整问句或短语，作用是吃搜索
· 每个词后面标注它的作用（进池 / 锁人群 / 吃搜索）
平台：【抖音 / 小红书】，并说明该平台下这组标签的优先级顺序。
```

```text
为这个选题推导发布时间：
1. 目标受众是谁（具体到身份和年龄段）
2. 他们一天中在哪些场景下会刷短视频
3. 给出 3 个建议时段，按优先级排序
4. 每个时段说明依据：为什么这个时间点这批人在刷手机
禁止使用"晚上 8 点是黄金时段"这类通用结论。
```
