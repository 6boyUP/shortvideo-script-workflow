# 质量门禁

## 出稿后 12 项自检

逐项过。哪项不过，退回重跑对应步骤，不要将就。

| 序号 | 检查什么 | 不通过怎么办 |
|---|---|---|
| 1 | 换行业测试：把行业名换成另一个行业，选题还成立吗 | 成立就是废话，删掉，重跑候选生成 |
| 2 | 反驳测试：有没有人可能不同意这条 | 所有人都点头，说明没信息量，重写核心判断 |
| 3 | 原型测试：5 条是不是一个味道 | 重跑淘汰环节，重申配额 |
| 4 | 时效测试：能不能说出具体时间和来源 | 说不出就是编的，重跑情报检索 |
| 5 | 信息量测试：第一句有没有具体名词或数字 | 全是抽象词，重写钩子 |
| 6 | 五秒测试：念一遍，五秒内能不能听出冲突 | 听不出就是铺垫太长，砍前半句 |
| 7 | 翻车测试：这版钩子靠什么前提成立 | 前提不真实，换一版钩子 |
| 8 | 时长测试：按每分钟 260 字念一遍 | 超时 20% 以上，砍内容不加速 |
| 9 | 结论测试：结尾有没有唯一结论 | 出现「看情况」，重做结构 |
| 10 | 话题测试：长尾词是按「用户怎么搜」写的吗 | 写成分类词就没用，重做话题 |
| 11 | 时间测试：发布依据能不能说出来 | 说不出就是抄的，重推时段 |
| 12 | 变现测试：能不能自然导向产品 | 需要硬转，说明选题与变现脱节，换选题 |

第 1 项和第 4 项是硬门槛，过不了这两条，后面全部作废。

## 八种失败模式与修法

| 症状 | 根本原因 | 修法 |
|---|---|---|
| 输出全是行业科普，没有观点 | 跳过了行业解构，直接生成 | 强制先输出四句话解构，再允许生成 |
| 5 个选题都是「避坑指南」 | 没执行配额制，模型走了最省力路径 | 写明「同原型超过 2 个即判定失败，重新生成」 |
| 钩子全是「你知道吗」 | 没指定机制，模型默认用最俗的开头 | 指定六种机制，要求标注机制名 |
| 时效证据查不到来源 | 跳过检索，凭训练数据编的 | 要求每条标时间 + 来源类型，标不出就删 |
| 核心判断都是「要重视、要科学」 | 没要求「可被反驳」 | 加一句「如果能被任何人同意，就重写」 |
| 时间建议全是晚上 8 点 | 没做受众作息推导 | 强制输出「受众在什么场景下刷手机」 |
| 话题标签堆了十几个大词 | 不理解平台差异 | 按 1:3:4 配比，区分抖音与小红书逻辑 |
| 内容没法导向产品 | 选题与变现脱节 | 打分时给「变现相关度」加权 |

## 最终判定

如果 5 条读起来都很正确、很专业、很全面，基本可以判定失败——它们不尖锐。尖锐的内容一定有立场，有立场就一定有人反对。没有人反对的选题，本质上是没有人关心的选题。
